# Pizza_sales_Analysis
🍕 Pizza Sales Analysis Dashboard
This project is a Power BI dashboard that analyzes pizza sales data to uncover key business insights. It is designed to help stakeholders understand trends, customer behavior, and sales performance.

Features
Sales Trends Over Time
Monthly and daily sales patterns with clear seasonal and weekly insights.

Top-Selling Pizza Categories & Sizes
Breakdown of performance by pizza category (Classic, Veggie, etc.) and size (S, M, L, XL).

Best & Worst Performing Pizzas
Identification of top and bottom performers by revenue and quantity sold.

Peak Sales Hours & Days
Heatmaps and bar charts showing when most sales occur.

Revenue, Quantity, and Orders KPIs
Key performance indicators (KPIs) at a glance.

Also Includes Sql File with SQL Queries Analysis.
